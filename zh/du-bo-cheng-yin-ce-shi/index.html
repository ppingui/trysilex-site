赌博成瘾测试：PGSI 的 9 道题

作者： Kyrylo Lozovyi · 2026年10月26日

简短回答： 这九道题就是 PGSI（问题赌博严重程度指数），来自加拿大问题赌博指数（Ferris 与 Wynne，2001）。总分 0 到 27 分；8 分及以上属于风险最高的一档。测试在你的浏览器里运行：什么都不保存，什么都不发送，也不问你的邮箱。

PGSI 问的是过去 12 个月。请按这段时间作答，不要按你最糟的那个月，也不要只看上周。对一个不会记住你答案的页面说实话，是最容易的诚实。

这不是诊断，而是基于标准问卷（PGSI）的风险快照。分数范围为 0 到 27。

答完全部九道题即可看到分数。

如何计分

每道题计 0 分（从不）、1 分（有时）、2 分（大多数时候）或 3 分（几乎总是），总分 0 到 27：

分数标准分档通常意味着什么
0没有问题过去 12 个月没有任何迹象。
1–2低风险出现了大多数偶尔赌一下的人没有的早期迹象。
3–7中度风险赌博更频繁、更重，往往已经带来一些经济或社会后果。
8–27问题赌博最高一档。这时通常需要结构化的帮助，而不只是意志力。

工具来源：Ferris, J. 与 Wynne, H.（2001），The Canadian Problem Gambling Index: Final Report，加拿大物质滥用中心。九个题目为本站自译。PGSI 是筛查工具；赌博障碍的诊断须由专业人员作出。

无论结果如何，下一步都一样

  • 在你和下注之间拉开距离。靠的不是意志力，而是阻力。先在手机上屏蔽赌博，再加上两道在脆弱时刻无法撤销的屏障：自我禁制和银行拦截（这里有说明）。
  • 弄懂冲动。它会升起又退去，通常在 20–30 分钟内，无论你赌不赌。这个规律就是你可以依靠的东西。

常见问题

多少分算赌博成瘾？

PGSI 中，0 分为没有问题，1–2 分为低风险，3–7 分为中度风险，8 分及以上通常被称为问题赌博。但这只是筛查，不是诊断：赌博障碍只能由专业人员诊断。

我的答案会被保存吗？

不会。分数在你自己的浏览器里计算，没有表单提交、没有 Cookie、没有追踪，也不要邮箱。关掉页面就没了。

可以替别人做吗？

PGSI 是作为自评工具验证的，替伴侣或家人作答只能得到大概的印象。下方的求助热线也接听家属的来电。

分数很低，但我觉得自己控制不住

相信这种感觉，而不是分数。PGSI 很看重经济和社会后果，处在高强度赌博初期的人可能分数很低，但依然陷入困境。
